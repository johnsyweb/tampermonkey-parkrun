parkrun Alphabet Challenge tracks the unofficial A–Z alphabet challenge on a parkrunner’s all-results page (e.g. [parkrunner A4100252](https://www.parkrun.org.uk/parkrunner/4100252/all/)).

## Challenge rules

A letter counts when you finish at an event whose name starts with that letter. **X is excluded** because there are no parkrun events whose names begin with X today, so the challenge is 25 letters.

Results are read oldest-first. The **first** qualifying finish for each letter is kept. Scanning stops once all 25 letters are done.

## What you see

A 5×5 grid of letters with a progress summary (letters completed, parkruns so far, and a completion date when finished).

Click a completed letter for a popup with the event and date. Click the overlay to close it.

**Save as Image** downloads a square tile sized for sharing on social media, including activity sites such as Strava.
