parkrun p-index progression charts how a parkrunner’s p-index grew across finishes on their all-results page (e.g. [parkrunner A1179626](https://www.parkrun.org.uk/parkrunner/1179626/all/)).

## What you see

A line chart of p-index against finish count, with markers where the index jumped and how large those gaps were.

A short plan summarises finishes since the last increase, the longest gap, and a minimum-finishes outline for reaching the next p-index (and the one after that), reusing existing events where possible.

When the current p-index is below 3, a note explains that early values can shift quickly.
