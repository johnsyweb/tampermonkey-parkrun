parkrun Compass Challenge visualises progress on the unofficial North / South / East / West challenge on a parkrunner’s all-results page (e.g. [parkrunner A1829613](https://www.parkrun.org.uk/parkrunner/1829613/all/)).

## Challenge rules

An event counts toward a direction when its name contains that direction as a case-insensitive substring (`north`, `south`, `east`, or `west`). One event name can contribute to more than one direction (for example a name containing both “north” and “east”).

Results are read oldest-first. The **first** qualifying finish for each direction is kept. The challenge is complete when all four directions are done.

## What you see

An SVG compass with progress stats and a completion date when finished.

**Save as Image** downloads a square tile sized for sharing on social media, including activity sites such as Strava.
