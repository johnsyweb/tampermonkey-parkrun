parkrun Cancellation Impact looks at gaps in an event’s history and shows how nearby alternatives performed on those cancelled Saturdays (e.g. [Warringal Parklands event history](https://www.parkrun.com.au/warringalparklands/results/eventhistory/)).

## Where it works

It runs on event history pages. A gap longer than seven days between events is treated as a cancellation window; dates considered are Saturdays inside that gap (including an ongoing gap through today when applicable).

## What you see

Nearby events within about 50 km are compared on each cancellation Saturday against a baseline from the twelve events before the gap (finishers and volunteers, absolute and percentage change).

A map, date navigation (**←** / **→**), and a sortable results table support exploration. The script also flags cases where nothing nearby appears to have run.

## Privacy and data

Public event lists and nearby histories may be cached in browser local storage. Requests run in your browser only.
