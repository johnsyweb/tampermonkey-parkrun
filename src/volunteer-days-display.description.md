parkrun Volunteer Days Display shows each finisher’s volunteer credit count on results pages, for celebration — without inventing run-to-volunteer ratios (e.g. [Fountains Abbey latest results](https://www.parkrun.org.uk/fountainsabbey/results/latestresults/)).

## What you see

Where the results table exposes volunteer credits (`data-vols` greater than zero), the script adds text such as `3 volunteer credits` in the detailed name cell.

It also adds **sort by volunteer credits** (ascending and descending) to the page’s existing sort control and, when present, the responsive sort dialog.
